In this project(replicating a previously existing website(Sellback)), I developed a replica website based on an existing commercial platform using HTML and CSS. The objective was to analyze a real-world website and recreate its structure, layout, navigation, typography, and visual design while maintaining academic integrity.The replica focuses on front-end development principles such as semantic HTML, responsive layouts, reusable components, and clean styling.

Along with the website implementation, I prepared a detailed Word report documenting the project workflow. The report includes an executive summary, project objectives and scope, site structure and navigation, design decisions, assets used, data sources, deployment steps, and reflection with future improvements. Screenshots and the live GitHub Pages URL were also included for verification.

To support data analysis and demonstrate backend-style thinking, I created an Excel workbook connected to the website content. The Excel file contains structured raw data representing website devices and services, calculation sheets using formulas such as SUM, AVERAGE, COUNTIF, and IF, and a summary dashboard with charts. Data validation, dropdowns, and analytics were used to simulate how real platforms manage and evaluate product data.

Finally, I prepared presentation slides to summarize the project for demonstration purposes, highlighting the website features, design choices, tools used, and learning outcomes. Overall, this project helped me strengthen my understanding of front-end development, documentation, data handling, and presentation skills, while simulating a complete real-world web development workflow.
